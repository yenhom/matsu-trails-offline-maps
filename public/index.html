怎麼放進手機

  1. 安裝 App。從上方挑一個 App，出發前先裝好。
  2. 下載路線。iPhone 的檔案存在「檔案」App，Android 通常在「下載」資料夾。如果在 LINE 或 Facebook 內開啟這個頁面，請先改用 Safari 或 Chrome 開啟再下載。
  3. 用 App 開啟。在檔案上點一下，或按「分享」，再選擇你安裝的 App。
  4. 下載馬祖的離線地圖。路線檔只有軌跡和航點，不含底圖。請趁有網路時，在 App 內下載馬祖地區的地圖。

出發前請先開啟飛航模式測試一次，確認路線和底圖都看得到。

使用前請留意

  • 路線僅供規劃參考，現場路況可能改變，請依現地標示與管制行走。
  • 各 App 的功能與收費可能調整，請以 App 商店的最新說明為準。
